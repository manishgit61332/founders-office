# Architecture decision records

ADRs capture decisions that future maintainers must understand. Accepted ADRs are immutable; add a new ADR that supersedes an old one when the decision changes.

Each ADR records status, date, context, decision, consequences, privacy/security impact, migration/rollback, and related work.
